# AI-Practice-Lab

My ongoing practice and exploration of AI.

This repository records my learning, experiments, observations, and insights around:

- Large Language Models (LLMs)
- Agent Skills
- AI Agents
- AI-assisted workflows

## Why I created this repository

I don't want to only learn AI concepts.

I want to learn through:

> Learn → Practice → Experiment → Measure → Reflect → Document

The goal is to gradually build practical understanding of how AI works in real-world tasks.
